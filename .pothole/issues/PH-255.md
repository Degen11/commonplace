# styles.js is a god file: every component's styles, the palette and global CSS in one 1,000-line module that changes with everything

Confirmed by detect-code: Facts verified: 1,022 lines; 215 commits in the window, the most of any file per the survey; 4 unrelated export groups (palette at :3, baseCSS at :31 to about :685, syncPillStyles, styles at :716, cardStyles at :1015); survey names it the change-coupling hub. Not generated, vendored or a barrel, so no trap. The CLAUDE.md single-file convention is documented intent but refutes only 'accidental', not the cost claim. Caveat for the gate: about 69% of commits are Claude sessions plus one human, so the cost is mainly two-file edits per UI change and parallel-session conflicts, not a large team serialising.
